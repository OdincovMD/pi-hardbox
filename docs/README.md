# PI Hardbox — документация

Прочитайте этот документ перед изменением проекта. Репозиторий объединяет
дашборд и VPN-шлюз: они используют общий контроллер смены ключа и восстановления.
При подготовке исходников в работающих каталогах `.gitnexus` не существовал.

- [Устройство дашборда](dashboard.md): три вкладки, PAM, вентилятор, проекты.
- [Устройство шлюза](gateway.md): маршруты, firewall, DNS и исключения.
- [Установка и обновление](deployment.md): пути, зависимости, конфиги и службы.
- [Подготовка публикации](../PUBLISHING.md): проверка Git и секретов.
- [Границы секретных данных](../SECURITY.md).

`dashboard/` содержит исходники, копируемые в `/opt/pi-dashboard`.
`gateway/` содержит управление шлюзом и примеры конфигурации.
`deploy/` содержит systemd/PAM-шаблоны. Работающие службы не запускаются
из Git checkout: упаковка и проверка проекта не меняют их состояние.

Точные адреса интерфейсов, домен сайта, пользователь admin и пути в шаблонах
соответствуют текущей PI Hardbox. Перед переносом на другую машину настройте
их согласованно; это проект конкретного сервера.
