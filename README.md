# PI Hardbox

Домашний Raspberry Pi 5: дашборд состояния и изолированная Wi-Fi-сеть через
VLESS/REALITY. Python использует стандартную библиотеку; аппаратные и сетевые
действия отделены от HTTP-сервера локальными Unix-сокетами.

- **Дашборд:** телеметрия, графики отдельных ядер, проекты и их доступность.
- **VPN:** состояние Wi-Fi, проверка и замена VLESS-ключа, прямые исключения
  для выбранных российских сервисов, обновление списков доменов.
  Автообновление base64-подписки выбирает рабочий профиль по задержке; ссылка
  и интервал настраиваются после входа.
- **Управление:** охлаждение с температурной защитой, статусы автозапуска,
  подтверждаемая перезагрузка. Вход через PAM-пароль системного admin.
- **img2txt:** синхронизация с проверенным основным ключом и перезапуск
  контейнеров; исходники самого приложения находятся в отдельном
  [репозитории img2txt](https://github.com/OdincovMD/img2txt/tree/xray).

Основной маршрут хоста, сайта и остальных контейнеров остаётся через Ethernet.
Только Wi-Fi-клиенты проходят через отдельный firewall и VPN; LLM-запросы
img2txt используют свой прокси с тем же основным ключом.

## Исходники

```text
dashboard/          сайт, контроллеры, тесты и публичные изображения
gateway/            управление firewall, безопасные примеры и генератор конфигов
deploy/             systemd, PAM и шаблоны установки
docs/               архитектура, эксплуатация и установка
tools/              проверки публикации и тесты этих проверок
```

Рабочие ключи, Wi-Fi-пароль, PAM-пароль, cookies, базы, DHCP leases,
резервные копии и журналы не входят в исходники. Примеры используют
демонстрационные значения и не подключаются к настоящей подписке.

## Проверка исходников

```bash
cd dashboard
python3 -m unittest -q test_fan_control.py test_cpu_telemetry.py test_vpn_control.py test_vpn_routing.py test_admin_control.py test_project_status.py test_img2txt_sync.py test_img2txt_llm_health.py test_vpn_subscription.py
cd ..
python3 -m unittest discover -s tools/tests -v
python3 tools/check_publication.py --staged
python3 tools/check_publication.py --history
```

Тесты охлаждения, перезагрузки и смены ключа используют подмены и временные
конфиги. Для HTTP-тестов требуется возможность открыть loopback-сокет.
Аппаратные сетевые проверки на работающем шлюзе запускаются отдельно.

Начните с [docs/README.md](docs/README.md). Исходники доступны в
[OdincovMD/pi-hardbox](https://github.com/OdincovMD/pi-hardbox), ветка main.
